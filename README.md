# 访谈英语 · 90天

每天 30 分钟，练习客户访谈、网络产品需求沟通和日常交流。

- 复习 5 分钟、词汇 10 分钟、句式 10 分钟、情景开口 5 分钟。
- 完整 90 天课程，222 个去重词或词组、132 条句式、354 条英式合成语音。
- 支持学习进度、间隔复习、备份导入导出和离线语音。
- 学习记录保存在各自设备，不上传到服务器。

站点正在开通，访问地址以成功部署结果为准。

## 在 iPhone 使用

用 Safari 打开发布后的网址，选择「分享 → 添加到主屏幕」。在「我的」里保存全部离线语音。
更换网址或手机前，先导出学习备份，再在新入口导入。

课程使用通用模拟工作场景，不包含真实客户访谈记录。
本项目使用公开的免费网页托管，不购买域名或付费服务器。
